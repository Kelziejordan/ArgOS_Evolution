# Organism Optimization & Adaptation System

This directory holds state evolution tools, sandbox mutation engines, and learning feedback models. Modifying parameters inside this module recalibrates how signals are classified but guarantees that core security locks are respected.

## 🗂️ Map
- `/organism-engine/evolution/`  - Genetic parameter loop trackers.
- `/organism-engine/mutation/`   - Controlled sandbox mutation executors.
- `/organism-engine/adaptation/` - Performance-based probability filters.
